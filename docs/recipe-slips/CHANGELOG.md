# Changelog

## 2026-11-27

- Photo reading now treats an underlined note as a heading.
- Fixed "cannot read properties of null" after an update: the phone was mixing old and new
  files. The app now checks every file is current before it starts.
- Slips now print lengthways down the paper, with much larger lettering.
- Yellow (unsure) words have a one-tap "Correct" tick.
- Names, random draw and pairs, with redraw (all or one person), undo and CSV export.
- Print all, print one, stop printing, and slip previews. The screen stays awake while
  printing. The "characters per line" setting has gone, as it no longer applies.
- The OpenRouter key now saves as soon as it's pasted, and Settings says whether one is saved.
- Photo reading (step 4, built early): take a photo of the post-its and a vision model
  fills the table. A second photo can be added. Key, model and colours are in Settings.
- QR code page (`qr.html`) for opening the app on a phone.
- Step 1: review table you can type into, with unsure words highlighted, a warning for
  short columns, undo, CSV export and import, and autosave.
- Early printer test: connect the PeriPage, print a sample slip, or show it on screen.
- Test page (`tests.html`).
